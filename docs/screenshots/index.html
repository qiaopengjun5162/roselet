灵感：Rose, Bud, Thorn 破冰游戏

一个经典的团队破冰方法——玫���代表感恩、尖刺代表焦虑、花苞代表期待。把它数字化，让社区在异步时空中持续「情绪破冰」。

第一屏：规则介绍

用户扫码进入，看到规则说明，点击「种一朵玫瑰」。

第二屏：种花交互

选颜色（红/白/黄），依次填写三种情绪，点击「种下玫瑰吧」。

第三屏：社区花圃

玫瑰种入花圃，各色玫瑰共同生长。AI 后台异步生成个性化回复。

玫瑰详情

点击任意一朵玫瑰查看详情，编辑/删除/点赞。

会员与钱包：一个入口，多链钱包

钱包登录是会员功能：后端发一次性随机数，钱包签名后验签绑定账号，签名不花手续费。右上角「连接钱包」是唯一入口，一个弹层同时列出 Solana 与 Aleo；会员权限由服务端校验，前端开关绕过不了。

90/10 Rust-TypeScript 架构

全部业务逻辑（情绪分析、推荐引擎、表单校验、状态机、粒子动画）在 Rust WASM 里，TypeScript 只是平台调用层 + 渲染壳。同一份 WASM 跨 Web 和小程序复用。938 个测试，90%+ 覆盖率。
